# 客户端 GUI · 设计规格

> 日期：2026-08-31 · 状态：设计批准，待实现
> 关联：`client/` 现有 Go CLI 客户端（M0–M3 已完成）

## 1. 背景与目标

`client/` 目前已实现 CLI 形态的监控订阅客户端（订阅 → 轮询 → 规则检测 → 报告）。本设计为其增加 **GUI 可视化控制台**，让用户通过浏览器图形化操作，而不改变底层业务逻辑（仍在本地 Go 进程执行）。

### 核心约束

* **单 exe 开箱即用**：发布版前端资源用 `go:embed` 打进 `mcmon.exe`，用户无需装任何环境，双击运行即用。

* **开发体验**：开发/调试期前端读取本地目录而非内嵌，改前端样式秒级生效，无需每次重编译。

* **架构边界**：客户端 = **本地进程 + 远程只读 API**。订阅、轮询、规则、快照、报告、统计监测全部在本地；远程主站仅作查询数据源，不知道用户订阅了谁、不存订阅数据。

## 2. 视觉方向（已定）

* 整体骨架：**① 侧栏导航**（左导航 + 右内容，分区切换）

* 搜索结果显示：**单查 → 卡片流；批查 → MC 列表行**，同一面板内 tab 切换

* 配色：**MC 像素风**（草绿高亮 `#7CB342` + 泥土米色内容背景 + 深灰导航 + Fusion Pixel 字体），延续主站视觉

## 3. 架构

沿用现有 Go CLI 骨架，新增**内嵌 Web 服务器**（`net/http` + 标准库，零外部依赖）。

```
浏览器(127.0.0.1:随机端口)  ⇄  本地 Go 进程(NET/HTTP+静态资源)  ⇄  远程主站 API(只读)
                                    │
                                    ├─ 订阅/轮询/规则/快照/报告（本地）
                                    ├─ config.json / subscriptions.json（本地）
                                    └─ snapshots/*.json（本地）
```

* 本地 HTTP 服务监听 `127.0.0.1:<随机端口>`，启动时用系统默认浏览器自动打开控制台。

* 浏览器仅是「操作面板」，所有业务逻辑仍在本地 Go 进程执行。

* 前端通过本地 HTTP API 与 Go 进程通信（见数据流）。

### 前端资源加载双模式

* **开发模式**（`--dev` 或构建 tag `dev`）：从 `client/web/` 本地目录读静态资源，改完刷新即生效。

* **发布模式**：`//go:embed web/*` 打入 exe。

## 4. 页面结构（侧栏导航）

| 导航项        | 功能                                                  |
| ---------- | --------------------------------------------------- |
| **可视化搜索**  | 单查（卡片流）/ 批查（MC 列表行），tab 切换，复用主站完整查询能力               |
| **订阅监控**   | 本地订阅的服务器实时状态（在线/人数/延迟/告警），轮询驱动刷新                    |
| **数据统计监测** | 基于 `snapshots/*.json` 的趋势图（在线人数/延迟波动/告警历史）          |
| **配置**     | 可视化编辑 `config.json` + `subscriptions.json`，写本地后回读刷新 |

## 5. 数据流

| 功能   | 前端                           | 本地 Go 进程                | 远程 API                            |
| ---- | ---------------------------- | ----------------------- | --------------------------------- |
| 搜索   | `POST /api/ping`             | 转发并解析                   | `ping_server / ping_batch` → 结果回显 |
| 订阅监控 | 长轮询/SSE `/api/monitor-panel` | 轮询器每轮写快照、收事件            | （只读，同搜索）                          |
| 统计   | `GET /api/stats?host=`       | 读 `snapshots/*.json` 聚合 | （无）                               |
| 配置   | `GET/PUT /api/config`        | 读写本地 json               | （无）                               |

### 新增本地 HTTP API（草案）

* `GET /api/state`：订阅清单 + 各服最新快照 + 运行状态（轮询间隔、是否在跑）

* `POST /api/ping` / `POST /api/ping/batch`：转发到远程主站查询（服务端能力复用）

* `GET /api/stats?host=&days=`：聚合 snapshots 出趋势数据

* `GET /api/config` / `PUT /api/config`：读/写配置（含校验）

* 静态资源：`GET /`（前端页面，dev 读目录 / 发布走 embed）

## 6. 错误处理 / 边界

* 远程 API 不可达 → 界面显示「数据源离线」占位，不崩。

* 本地快照缺失 → 图表显示空态引导。

* 端口占用 → 自动尝试下一个端口。

* 配置校验失败（配置页）→ 内联错误提示，不覆盖原文件。

## 7. 测试

* 现有 Go 结构体 / 规则引擎逻辑不与 UI 耦合，保持可单测。

* 新增单测：`/api/config` 读写、`/api/ping` 转发、快照聚合。
